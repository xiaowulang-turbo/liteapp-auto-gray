# Liteapp 灰度自动上线

油猴脚本（Tampermonkey），自动检测并点击 Liteapp 运营平台的「灰度上线」按钮，弹窗中自动确认，实现灰度发布全流程自动化。

## 特性

- 🚀 **自动点击灰度上线按钮** — 倒计时结束后立即触发
- ✅ **弹窗自动确认** — 弹出确认窗口后 0.5 秒内自动点击「确定」
- 🛡️ **Web Worker 抗后台节流** — 后台 tab 不受 Chrome 定时器节流影响
- 📍 **visibilitychange 监听** — 切回前台时立即检查，不错过时机
- 🔒 **防重复点击** — 30 秒内不会重复触发

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 Tampermonkey 图标 → 「添加新脚本」
3. 将 `liteapp-auto-gray.user.js` 内容粘贴进去
4. 保存（Ctrl+S / Cmd+S）

## 匹配页面

```
https://lite.weixin.woa.com/console/*/release/change/info/*
```

## 工作原理

```
倒计时结束 → 自动点击「灰度上线」
    ↓
弹窗出现 → 0.5s 内检测 → 自动点击「确定」
    ↓
等待下一轮灰度倒计时 → 循环...
```

### 后台 Tab 抗节流

Chrome 对后台 tab 的 `setInterval` 有严重节流：
- 后台 < 5 分钟：最少 1 秒执行一次
- 后台 > 5 分钟：最少 60 秒执行一次（intensive throttling）

本脚本使用 **Web Worker** 在独立线程中保持 3 秒精准心跳，不受主线程 tab 节流影响。
